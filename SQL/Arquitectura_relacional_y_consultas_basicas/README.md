
# 🗄️ Arquitectura relacional y consultas básicas en SQL

## 📝 Descripción del proyecto

En este desafío trabajé con los fundamentos de las **bases de datos relacionales** y la realización de consultas básicas utilizando **SQL**.

El caso corresponde a una empresa de ventas multicanal que busca reemplazar el uso de hojas de cálculo por una base de datos relacional centralizada.

El objetivo fue analizar la estructura de la base de datos, comprender las relaciones entre sus tablas y realizar consultas que permitieran obtener información útil para la toma de decisiones.

---

## 🎯 Objetivos del desafío

El trabajo se dividió en tres etapas principales:

1. 🧩 Analizar el diseño lógico y las relaciones del modelo de datos.
2. 💻 Realizar consultas básicas utilizando SQL.
3. 💡 Reflexionar sobre las ventajas y posibles mejoras de una base de datos relacional.

---

## 🧩 Diseño lógico del modelo de datos

En esta etapa se analizaron las entidades que forman parte de la base de datos.

Se trabajó en:

- 📋 Identificación de las principales entidades.
- 🏷️ Identificación de sus atributos.
- 🔑 Reconocimiento de claves primarias.
- 🔗 Análisis de las relaciones entre las tablas.
- 🗺️ Representación mediante un **Diagrama Entidad-Relación (DER)**.

Este análisis permite comprender cómo se encuentra organizada la información antes de comenzar a realizar consultas.

📄 [Ver diseño lógico y análisis del modelo de datos](1.%20Dise%C3%B1o%20l%C3%B3gico%20y%20an%C3%A1lisis%20del%20modelo%20de%20datos.pdf)

## 💻 Consultas básicas en SQL

Posteriormente se realizaron consultas SQL para extraer información desde la base de datos.

Entre las consultas desarrolladas se encuentran:

- 👤 Listar nombres y correos de clientes de **Valparaíso**.
- 📅 Mostrar las ventas realizadas durante **junio**, incluyendo el nombre del cliente y el total.
- 🏪 Obtener el total de productos vendidos por tienda.

Estas consultas permitieron practicar la búsqueda, filtrado y agrupación de información almacenada en diferentes tablas.

💻 [Ver archivo con las consultas SQL](2.%20Escritura%20de%20consultas%20b%C3%A1sicas%20en%20SQL.sql)

## 💡 Reflexión sobre bases de datos

Como parte final del desafío se realizó una reflexión sobre el uso de bases de datos relacionales dentro de una organización.

Se analizaron principalmente:

- 📊 Las ventajas de utilizar una base de datos relacional frente al uso de hojas de cálculo.
- 🔗 La organización y relación de la información.
- 📈 La posibilidad de trabajar con una mayor cantidad de datos.
- 🛠️ Posibles mejoras para hacer el modelo más escalable.

# 🔍 Explorando relaciones y consultas avanzadas en SQL

## 📝 Descripción del proyecto

En este desafío continué trabajando con una **base de datos relacional**, utilizando consultas SQL más avanzadas para obtener información desde distintas tablas.

El objetivo fue aplicar relaciones entre tablas, funciones de agregación, filtros y subconsultas para responder diferentes requerimientos de análisis.

---

## 🎯 Objetivos del desafío

Durante el desarrollo se trabajó principalmente en:

1. 🔗 Combinar información de diferentes tablas mediante **JOIN**.
2. 📊 Utilizar funciones de agregación para resumir información.
3. 🔎 Aplicar la cláusula **HAVING** para filtrar resultados agrupados.
4. 🧩 Crear **subconsultas** para realizar análisis específicos.
5. 🔐 Analizar la importancia de la **integridad referencial** en una base de datos.

---

## 🔗 Relaciones entre tablas — JOIN

Se utilizaron consultas con **JOIN** para relacionar información almacenada en distintas tablas.

Entre los análisis realizados se encuentran:

- 👤 Nombre del cliente.
- 📦 Producto comprado.
- 🏪 Tienda donde se realizó la compra.
- 📅 Ventas realizadas durante julio.
- 🌎 Total de ventas agrupadas por ciudad de la tienda.

Esto permitió obtener información que se encontraba distribuida en diferentes tablas de la base de datos.

---

## 📊 Funciones de agregación y HAVING

También se utilizaron funciones de agregación para resumir y analizar los datos.

Se realizaron consultas para:

- 📦 Obtener la cantidad total vendida por producto.
- 🔎 Mostrar productos con más de una unidad vendida.
- 🏪 Calcular la cantidad de ventas realizadas por cada sucursal.
- 💰 Obtener el promedio del total vendido por venta.

La cláusula **HAVING** permitió aplicar condiciones sobre los resultados agrupados.

---

## 🧩 Subconsultas

Se utilizaron subconsultas para realizar análisis más específicos.

Entre ellas:

- 💰 Identificar clientes que realizaron compras superiores al promedio general de ventas.
- 🏆 Identificar el producto más caro vendido.

Las subconsultas permiten utilizar el resultado de una consulta dentro de otra consulta para obtener información más específica.

---

## 🔐 Integridad referencial

Como parte del desafío también se realizó un análisis sobre la **integridad referencial**.

Este concepto permite mantener relaciones coherentes entre las tablas mediante el uso de claves primarias y claves foráneas.

También se analizaron posibles mejoras en la estructura de la base de datos en caso de incorporar nuevos procesos, como **devoluciones o reclamos**.
